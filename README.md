# Coffee Shop Digital Menu

An elegant digital cafe menu card component featuring responsive category filtering, dotted leader lines, and warm artisanal typography.

## Features
- Interactive category tabs (Espresso, Cold Brews, Bakery, All)
- Dotted leader lines aligning names and prices with CSS Flexbox
- Google Fonts pairing (Playfair Display & Plus Jakarta Sans)
- Responsive layout for desktop and mobile

## Preview
Open `index.html` in your browser.
